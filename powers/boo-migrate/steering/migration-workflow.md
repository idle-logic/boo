# Migrating with Boo

1. **Collect** the old data as it is: a CSV export, or the demo app from `boo_sample_old_app`.
2. **Analyse** with `boo_raise_csv` or `boo_find_workarounds`. Show each finding with its count and one real example, old beside new.
3. **Clean.** Ask only the real choices. Run every correction through `boo_check_changes` first.
4. **Migrate** the clean files into the new software.
5. **Verify** with the certificate. AT REST means done. STILL HAUNTED means keep going, and say what is missing.

Rules:

- A count, a dollar amount or a verdict comes only from a Boo tool result in this session.
- Money owed by a client is never credit.
- Crossed-out text on paper is no longer true.
- Short, plain English. No em dashes.
