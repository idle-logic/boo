# Haunt

Haunt is an AI agent that switches a business from the software it has outgrown into new software, and proves nothing was lost.

## The problem

Salons, spas and clinics stay on booking software they dislike because leaving it is painful. The export, if there is one, has names and phone numbers but not package balances, store credit, notes, staff skills, deposits, clean-up times or cancellation rules. There is rarely an API. So someone retypes everything for days, and something always gets lost.

## What Haunt does

1. **Read.** Goes through every screen of the old app the way a person would, and writes down everything, including what no export contains.
2. **Plan.** AI maps the old app's words onto the new app's (categories, health notes that should be alerts, people entered twice). Every AI answer is checked; plain rules stand in if the AI is unavailable.
3. **Move.** Several agents enter it all into the new app at once, through the new app's own screens.
4. **Prove.** Makes the same test bookings in both apps and compares price, end time, deposit and fees, then reads every record back. Differences are investigated and fixed, or brought to the owner.

## Principles

- **The old app is only read.** Haunt never changes it.
- **No export file and no API.** Haunt uses the apps' screens, so it works with any software.
- **Ask, don't guess.** Anything that is a real choice goes to the owner as one clear question, while the rest of the work carries on.
- **Prove it.** A switch is done when the checks match, not when the typing stops.
